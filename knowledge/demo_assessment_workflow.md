guideline and must not be used for patient care.

## 1. Purpose of the assessment section

The assessment section records the clinician’s working formulation of the problem
list after history and examination. In this demo workflow, the assessment section
should list active problems in priority order and note uncertainty explicitly.

## 2. Required elements

1. Problem statement in plain language.
2. Supporting findings that motivated the assessment.
3. Differential considerations when diagnosis is not established.
4. Plan linkage: each problem should point to a corresponding plan item.

## 3. What the assessment section must not do

- It must not replace a formal diagnosis code when coding is required by the
  facility record system.
- It must not assert certainty when evidence is incomplete.
- It must not generate autonomous treatment orders.
