# Knowledge folder

Only add documents for which BRAHMO has documented rights for the intended use and which have passed the appropriate clinical/source verification workflow.

Do not add patient records, identifiable data, unlicensed material, or unreviewed medical guidance. The local search prototype indexes `.md` and `.txt` files other than this README. It performs simple lexical matching only; it does not validate clinical correctness, source authority, currentness, population applicability, or licensing.
